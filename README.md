# Досье Danger Gal (личный модуль кампании)

Манифест: https://raw.githubusercontent.com/samroaleksej-bit/night-city-map/nc-dossiers/module.json

Мастер: кнопка «Досье Danger Gal» (значок папок) в панели токенов → выбрать досье и папку → «Открыть» или «Показать игрокам».
Макрос: `NCDossiers.show("snow", "enemies")` · `NCDossiers.open("snow")` · `NCDossiers.panel()`

## Раздатки · Химик (0.7.0)

В той же панели, отдельным блоком: схема дома и план здания (переключение внизу, клик — увеличить), анимированный план 2077, три терминала (база Гончих, хата Химика, порт) со звуком и вкладкой «СЕТЬ» для взлома по правилам RED. Ход взлома общий для всех, если включён модуль Night City Map 0.24+.
