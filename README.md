# Книга Длани Симори (личный модуль кампании)

Реестр экспедиции Ордена в виде книги: досье героев и раздатки листаются как страницы.

Манифест: https://raw.githubusercontent.com/samroaleksej-bit/night-city-map/jungle-book/module.json

Мастер: кнопка с книгой в панели токенов → выбрать раздел → «Открыть» или «Показать игрокам».
Галочка «Игроки листают следом за мастером»: мастер переворачивает страницу - у игроков открывается тот же разворот.
Макросы: `JungleBook.show(3)` · `JungleBook.open(0)` · `JungleBook.panel()` · `JungleBook.goto(5)` (число - номер разворота).

## Как править
- Тексты и порядок страниц: `book/pages.js`. Страница 0 - обложка, нечётные слева, чётные справа.
- Оглавление панели мастера: `book/toc.json` (название и номер разворота).
- Портреты: положить в `book/img/` файлы `hazar.webp`, `sinmin.webp`, `regilion.webp`, `raize.webp`, `kraik.webp`. Пока файла нет, на его месте буква.
- В книгу писать только то, что можно видеть игрокам.
