# Клятвопреступник - подкласс паладина (D&D 2024)

Модуль для Foundry VTT v14 и системы dnd5e 6.x. Добавляет компендиум «Клятвопреступник» с подклассом и его умениями на русском.

## Как выдать герою
1. Откройте компендиум «Клятвопреступник».
2. Перетащите предмет **Клятвопреступник** на лист паладина 3 уровня или выше.
3. Умения выдадутся сами по уровням: 3, 7, 15 и 20.

## Что автоматизировано
- **Призыв нежити** и **Жуткий облик** тратят применение Божественного канала.
- **Жуткий облик** - спасбросок Мудрости по Сл. заклинаний и состояние «испуганный» на 1 минуту.
- **Аура ненависти** - бонус некротического урона к вашим рукопашным атакам оружием.
- **Сверхъестественное сопротивление** - сопротивление дробящему, колющему и рубящему урону.
- **Повелитель ужаса** - одно применение на продолжительный отдых, атака «Удар тени» и бросок урона «Страх».

## Что делается вручную
- Токены скелетов и зомби для «Призыва нежити».
- Заклинания клятвопреступника: перетащите их из своего компендиума и отметьте «всегда подготовлено».
- Бонус Ауры ненависти для союзной нежити и исчадий.
