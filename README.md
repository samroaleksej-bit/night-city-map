# Русский перевод модулей (CPR-набор)

Отдельный модуль-перевод. Оригиналы не трогает, обновления модулей перевод не затирают.
Каждый перевод подключается, только если соответствующий модуль включён в мире.

Язык клиента: Настройки → Настроить → Язык = Русский.

Не переведено: Pneuma's Crew Tools (нет языкового файла, текст в коде), часть Pneuma's Visual Tools.
